# Project Function List

## Nama Project

**Tabletop Player Sheet Manager**

### 1. `buatKarakter()`

**Kegunaan:**

Digunakan untuk membuat character sheet baru dengan informasi seperti nama, ras, class, level, dan ability score.

### 2. `tampilkanKarakter()`

**Kegunaan:**

Digunakan untuk menampilkan informasi lengkap dari character sheet.

### 3. `editKarakter()`

**Kegunaan:**

Digunakan untuk mengubah informasi karakter yang sudah tersimpan.

### 4. `hapusKarakter()`

**Kegunaan:**

Digunakan untuk menghapus character sheet dari sistem.

### 5. `cariKarakter()`

**Kegunaan:**

Digunakan untuk mencari karakter berdasarkan nama atau ID karakter.

### 6. `hitungModifier()`

**Kegunaan:**

Digunakan untuk menghitung ability modifier berdasarkan ability score karakter.

### 7. `ubahHP()`

**Kegunaan:**

Digunakan untuk menambah atau mengurangi HP karakter, misalnya ketika menerima damage atau mendapatkan healing.

### 8. `tambahXP()`

**Kegunaan:**

Digunakan untuk menambahkan experience point (XP) kepada karakter.

### 9. `cekLevelUp()`

**Kegunaan:**

Digunakan untuk memeriksa apakah XP karakter sudah memenuhi syarat untuk naik level.

### 10. `tambahInventory()`

**Kegunaan:**

Digunakan untuk menambahkan item baru ke inventory karakter.

### 11. `hapusInventory()`

**Kegunaan:**

Digunakan untuk menghapus item dari inventory karakter.

### 12. `tampilkanInventory()`

**Kegunaan:**

Digunakan untuk menampilkan seluruh item yang dimiliki karakter.

### 13. `tambahSpell()`

**Kegunaan:**

Digunakan untuk menambahkan spell yang dimiliki atau dikuasai karakter.

### 14. `hapusSpell()`

**Kegunaan:**

Digunakan untuk menghapus spell dari daftar spell karakter.

### 15. `tampilkanSpell()`

**Kegunaan:**

Digunakan untuk menampilkan daftar spell yang dimiliki karakter.

### 16. `simpanData()`

**Kegunaan:**

Digunakan untuk menyimpan data character sheet agar dapat digunakan kembali.

### 17. `muatData()`

**Kegunaan:**

Digunakan untuk mengambil dan memuat data character sheet yang telah disimpan.

### 18. `validasiData()`

**Kegunaan:**

Digunakan untuk memastikan data yang dimasukkan pengguna sesuai dengan format yang diperlukan.

### 19. `resetKarakter()`

**Kegunaan:**

Digunakan untuk mengembalikan data karakter ke kondisi awal atau mengatur ulang character sheet.

### 20. `handleError()`

**Kegunaan:**

Digunakan untuk menangani kesalahan input atau kesalahan saat aplikasi menjalankan suatu proses.
